# 三页线框与视觉说明（Wireframes）

> 配套可视化预览（暗色主题）：首页/概览、文档管理、问答三栏（见设计评审演示）。
> 所有页面：dark-first，单一 accent `#3E63DD`，琥珀签名色 `#F5B544`；图标全 Lucide 16/20/24px；圆角 6/12/16/pill；间距 4px 网格。

## 2. 文档管理页（Knowledge Management）

```
┌──────────────────────────────────────────────────────────┐
│ Header（同首页）                                           │
├────┬─────────────────────────────────────────────────────┤
│ 文 │ [搜索文档…]  状态▾        [ 上传文档 ](accent)       │
│ 档 │ 名称            页数   分块   状态           ⋮        │
│ 库 │ ┌──────────────────────────────────────────────┐   │
│ ⌁  │ │ ▣ 手册.pdf        12页   48   [已索引]        ⋮ │   │
│ 问 │ ├──────────────────────────────────────────────┤   │
│ ⌁  │ │ ▣ 年度报告.pdf    48页  192  ●○ 解析中       ⋮ │   │
│ 评 │ ├──────────────────────────────────────────────┤   │
│ 测 │ │ ▣ 合同范本.pdf    23页   91   [已索引]        ⋮ │   │
│ ⌁  │ ├──────────────────────────────────────────────┤   │
│ 设 │ │ ▣ 加密财报.pdf   —页    —   [失败]文档已加密  │   │
│ 置 │ │                                  [重试]      ⋮ │   │
│    │ └──────────────────────────────────────────────┘   │
└────┴─────────────────────────────────────────────────────┘
```

- **顶部**：搜索框 + 状态/类型筛选 + 「上传文档」主按钮(accent)。
- **列表行**：类型图标(Lucide FileText 20px) · 文件名(fg) · 页数(meta) · 分块数(meta) · 状态徽章(语义色) · 操作菜单(ghost 三点)。
- **状态九态**：已索引(success) / 解析中(Stepper 节点) / 失败(danger 边 + 具体原因 + 重试) / 排队(meta) / 空(见下)。
- **空状态**：居中 `FileText`(24px) + 「拖入 PDF，开始构建你的可溯源知识库」+ 上传入口。
- **点击行**：右侧抽屉展示分块预览、溯源段落、向量状态、删除/重新解析。

## 3. 问答页（Chat + PDF 溯源预览 · 签名功能）

```
┌──────────────────────────────────────────────────────────┐
│ Header                                                     │
│ [LLM后端 Ollama▾] [模型 qwen2.5:7b▾]  Rerank ●             │ 双后端选择器
├──────┬───────────────────────────┬───────────────────────┤
│ 文档 │  用户: 第三章主要结论？    │ ┌─ PDF 预览 ─────────┐ │
│ 面板 │                           │ │ 定位 p.12 / 24        │ │
│ ┌──┐ │  助手: 结论见第十二页与第 │ │ ┌────────────────┐  │ │
│ │上传│ │  十五页，详见引用标记。 │ │ │████████████████│  │ │
│ └──┘ │  [1] [2]                 │ │ │████████████████│  │ │
│ ▣手册│ │                        │ │ │▓▓▓▓ 高亮块 ▓▓▓▓│  │ │ ← 引用高亮
│ ▣合同│ │                        │ │ │████████████████│  │ │
│ ▣年报│ │  ┌────────────────────┐│ │ └────────────────┘  │ │
│      │ │  │ 输入问题…        > ││ │      p.12           │ │
│      │ │  └────────────────────┘│ └───────────────────────┘ │
└──────┴───────────────────────────┴───────────────────────┘
```

- **三栏工作区**：左 文档面板(上传 + 列表) | 中 对话(用户右/助手左，内联 `[n]` 角标) | 右 PDF 原文预览。
- **双后端选择器（顶部常驻）**：LLM 后端切换(Ollama/OpenAI 兼容) + 模型名下拉 + Rerank 开关，方便评测对比。
- **引用角标 `[n]`**：`<button>` + Radix Tooltip「文档名 · p.12」；点击跳 PDF 对应页并高亮；反向 hover PDF 高亮块 → 角标浮现 accent 环。
- **PDF 高亮（降级→升级）**：
  - 降级（当前）：翻页(200ms 淡入) + **整页高亮**（顶部 accent 条 + 极淡 citation 叠加 + 一次性脉冲 220ms）。
  - 升级（bbox 到位）：按 `bbox` 叠加琥珀矩形(`fill citation-fill` + `1.5px citation`)。
  - 数据结构：`citation = { index, docId, docName, page /*必带*/, bbox? /*可选*/, snippet? }`。
- **状态**：Loading(流式打字机) / Empty(引导首问 + 真实示例「本文档第三章主要结论是什么？」) / Error(具体错误 + 重试) / KB 空(问答区禁用 +「请先上传文档」遮罩)。
- **响应式**：移动端 文档面板→顶部抽屉，对话为主，PDF→全屏弹层（底部「原文」入口）。
